# AI-Powered NLP Document Intelligence Platform

A brief case study showcasing my experience in requirements management, cross-functional team coordination, sprint tracking and production delivery in an AI/NLP project.

## Repository Contents

| File | Description |
|---|---|
| `AI-Powered NLP Document Intelligence Platform.pdf` | Detailed project case study covering project overview, responsibilities, execution and outcomes. |
| `AI_Document_Intelligence_Project_Management_Tracker.xlsx` | Reusable Excel template for project dashboard, sprint tracking, risk register, milestones and weekly status. |

## Project Highlights
- 20+ cross-functional team members
- 8 two-week sprints
- Requirements and stakeholder management
- Excel-based project tracking
- Testing, UAT and production delivery support

**Note:** The Excel workbook is a reusable template, not the original project tracker.
